# MDX: Markdown + JSX = 🚀

Welcome to the **MDX demo page**! MDX lets you write JSX directly in your Markdown files, combining the simplicity of Markdown with the power of components.

## 🎯 What Makes MDX Special?

MDX extends Markdown by allowing you to:

1. **Import and use components**
2. **Write JSX expressions**
3. **Create interactive content**
4. **Mix Markdown and React/Astro components**

## 📦 Component Imports

With MDX, you can import components at the top of your file:

<Code code={`import Button from '../components/Button.astro';
import { Code } from 'astro/components';
import Chart from '../components/Chart.jsx';`} lang="jsx" />

## 🔧 JSX in Markdown

### Inline JSX Expressions

You can use JavaScript expressions directly in your content. For example, today's date is: **{new Date().toLocaleDateString()}**

The current year is {new Date().getFullYear()} and 2 + 2 equals {2 + 2}.

### JSX Code Blocks

## 📊 Use Cases for MDX

MDX shines when you need:

1. **Interactive Documentation** - Embed live code examples
2. **Blog Posts with Demos** - Show working examples alongside explanations
3. **Component Galleries** - Display components with their code
4. **Educational Content** - Create interactive tutorials

## 🚦 MDX vs Markdown vs Astro

| Feature | Markdown | MDX | Astro |
|---------|----------|-----|-------|
| Simple content | ✅ Best | ✅ Good | ❌ Overkill |
| Component imports | ❌ | ✅ | ✅ |
| JSX expressions | ❌ | ✅ | ✅ |
| Full programming | ❌ | 🟡 Limited | ✅ Best |
| Learning curve | 📗 Easy | 📙 Medium | 📕 Harder |

## 💡 Tips for Using MDX

### Do's ✅
- Use MDX for content that needs interactivity
- Keep components simple and focused
- Leverage the mix of Markdown and JSX
- Use for documentation with live examples

### Don'ts ❌
- Don't use MDX for simple static content
- Avoid complex logic in MDX files
- Don't treat it as a full application framework
- Keep heavy computations in separate components

## 🔮 Example: Interactive Counter

export const Counter = () => {
  const [count, setCount] = React.useState(0);
  
  return (
    <div style={{
      background: '#f3f4f6',
      padding: '1rem',
      borderRadius: '0.5rem',
      textAlign: 'center'
    }}>
      <p>Count: {count}</p>
      <button
        onClick={() => setCount(count + 1)}
        style={{
          background: '#3b82f6',
          color: 'white',
          padding: '0.5rem 1rem',
          borderRadius: '0.25rem',
          border: 'none',
          cursor: 'pointer'
        }}
      >
        Increment
      </button>
    </div>
  );
};

*Note: The counter above would work with proper React setup in MDX*

## 🎬 Conclusion

MDX bridges the gap between Markdown's simplicity and component-based development. It's perfect for:

- Technical documentation
- Interactive blog posts  
- Component showcases
- Educational materials

To use MDX in your Astro project, install the integration:

<Code code="npm install @astrojs/mdx" lang="bash" />

Then add it to your `astro.config.mjs`:

<Code code={`import { defineConfig } from 'astro/config';
import mdx from '@astrojs/mdx';

export default defineConfig({
  integrations: [mdx()]
});`} lang="js" />
